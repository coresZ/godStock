# 天梯 v1.3.1

Windows x64 便携版。解压后双击 `TianTi.exe`，首次启动会在同目录创建 `data/`。

v1.3.0 的收尾补丁：不改策略规则与数据表，只修正 1 分钟线 / 分时的取数与界面标注，并把逐分钟事件的行内时点收进悬停提示。

## 2026-11-20 修订

### 时间轴

- 逐分钟事件行内只保留「炸板 / 首封 / 开板」与开板次数，**具体时点不再写进行内**：所在分钟已经显示在左侧时间列，重复的时间收进悬停提示。
- 首封、炸板的完整时间仍在 hover 与导出 TXT 里，导出格式不变。
- 泳道上的补充落点改为**虚线空心点 + 中性灰**，与主事件的实心点区分；悬停时提亮，计数规则不变。

### 1 分钟线与分时

- 后端改为显式标记数据来源（东方财富 / 腾讯点位），不再用「K 线是否全平」反推来源：一字板的真实 1 分钟线不会被误判成腾讯点位而跳过落库。
- 分时走腾讯兜底时，底部脚注显示「腾讯分时 · 分时」与「东财分钟接口不可达 · 腾讯分时点位（仅收盘价）」，不再一律写成东方财富。
- 1 分钟 K 线加载失败时补一句「1 分钟线没有备用源；可切到「分时」用腾讯点位看走势」，不再只给一行报错。
- 所有周期都先读缓存、再后台刷新；分时抓到的真实 1 分钟数据照常写入缓存，腾讯点位永不落库。
- 伪 1 分钟缓存的判据只看 OHLC 是否全等，不再依赖成交量（腾讯点位的成交量差分后通常不为 0，旧判据几乎不命中）。

### 文档

- `README.md` / `release/README.md`、`docs/DESIGN.md` / `release/DESIGN.md`、`release/使用说明.txt` 同步行内时点、虚线落点与分时兜底标注。
- 修正 v1.3.0 发行说明里「1 分钟请求绕过旧缓存」的过时描述。

## 说明

- 策略规则、四张表、7 个 command 与 v1.3.0 完全一致。
- 本机到东方财富分钟接口不可达，腾讯分时兜底只在接口层面验证过，**没有盘中画面截图**；1 分钟 K 线的提示态同样未截图。
- 时间轴的悬停提示与导出只在代码层验证，未在 exe 里逐项点过。

## 数据来源

与 v1.3.0 相同：涨停 / 炸板 / 跌停 / 连板 / 板块 / 历史涨停池同花顺；指数与实时报价 腾讯 → 新浪 → 东财；K 线与分时 东财为主、腾讯备用。
