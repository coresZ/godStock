# 天梯 v1.4.1

Windows x64 便携版。解压后双击 `TianTi.exe`，首次启动会在同目录创建 `data/`。

v1.4.0 的补丁：分时弹窗切日不再整页闪烁，只更新弹窗内部。

## 2026-11-20 修订

### 分时弹窗

- 双击日 / 周 / 月 K 线打开分时后，点 ‹ › 或键盘 ← → 切换交易日，**只更新弹窗内的标题、价格、涨跌与分时图**，不再关闭重建浮层，遮罩不会消失一帧，整页不再闪一下。
- 切换时保留旧分时直到新数据返回；底部来源先显示「读取中…」，成功后变回「东方财富 1 分钟 / 腾讯分时点位 / 本地缓存」。
- 连续快速点击时用请求序号丢弃过期响应，最终停在最后点击的那一天；取不到数据时仍给出可读原因。
- 首次双击打开展示加载态、`Esc` / 右上角 × / 点遮罩关闭的行为保持不变。

### 说明

- 本次只改前端弹窗的更新方式，数据接口、策略规则与缓存逻辑与 v1.4.0 完全一致。
- 切日行为用 dev mock 验证：弹窗与 canvas 节点在切换前后未被重建、加载文案与图表确实更新、连点 5 次无空态；**未在真实盘中数据下逐日截图**。

## 数据来源

与 v1.4.0 相同：涨停 / 炸板 / 跌停 / 连板 / 板块 / 历史涨停池同花顺；指数与实时报价 腾讯 → 新浪 → 东财；K 线与分时 东财为主、腾讯备用。
