# 天梯 v1.4.0

Windows x64 便携版。解压后双击 `TianTi.exe`，首次启动会在同目录创建 `data/`。

## 2026-11-20 修订

### K 线双击看当天分时（新增）

- 在日 / 周 / 月 K 线上**双击任意一根**，弹出当天的分时浮层：名称、代码 · 日期、收盘与涨跌，右上是相邻交易日切换与关闭。
- 浮层内可以用 ‹ › 或键盘 ← → 切换相邻交易日；`Esc`、右上角 ×、点遮罩都能关闭，K 线上下文不丢。
- 取数顺序：本地分时缓存 → 东方财富 1 分钟（按日 beg/end）→ 腾讯 `day/query`（近 5 个交易日；命中一次就把 5 天都落库）。
- 指数同样支持：上证 / 深证 / 创业板用 `1.000001` 这类 secid 取数。
- 取不到时给一句可读的原因，不弹空图；浮层底部标注数据来源（东方财富 1 分钟 / 腾讯分时点位 / 本地缓存）。
- 新增表 `intraday_bars`，只写分时缓存；设置里的「清理缓存」会一起清掉。

### 策略漏斗下钻（新增）

- 「首板 / 硬过滤 / 候选 / 观察」四个数字改成按钮：点哪一档，下方就换成哪一档的个股。
- 首板按首封时间排列，硬过滤按观察名次与规则分排列；结果列写「观察 #n / 候选 / 待补」或卡住的规则（中文标签，不再是规则代码）。
- 候选 / 观察仍用原来的详细表：观察只显示规则分前 N，候选显示全部，并保留「显示被剔除」。
- 阶段行点按或 `Enter` 直接进 K 线；切阶段只重绘策略区，保留滚动位置。

### 数据与接口

- 新增 command `get_intraday(code, date)`；指数可传 secid。
- `ScreenResult` 增加 `stocks`（当日涨停池每只票的阶段标记），原有 `universe` / `hardPassed` / `candidates` 计数口径不变。
- 1 分钟 K 线的取数规则不变：只认东方财富，取不到用本地缓存并提示；分时仍允许腾讯点位兜底。

### 细节修复

- 分时右轴「最新价标签」压住刻度文字：标签高 16px，避让阈值从 10px 提到 15px。
- 策略阶段 chip 与旧「被剔除」样式类名冲突，拆成 `.strategy-fail-chips`。
- 文档与截图同步：README / DESIGN / 使用说明补上双击分时与漏斗下钻，新增 `docs/screenshots/intraday-dark.png` 与 `intraday-light.png`。

## 说明

- 本机到东方财富分钟接口不可达：**超过 5 个交易日的历史分时**依赖东财 `beg/end` 路径，代码与编译已通过，但没有实机验证；腾讯兜底只覆盖近 5 个交易日，超出会明确提示。
- 策略阶段数据在真实后端只做了编译与构造逻辑核对，**没有在实盘快照上跑过**；交互是用 dev mock 验证的。
- P5 回测仍未实现（策略库标「规划中」）；09:25 竞价仍只做实时采样，未在实盘验证。
- 以上仅为按固定规则筛出的复盘候选，不构成投资建议。

## 数据来源

- 涨停 / 炸板 / 跌停 / 连板 / 板块 / 历史涨停池：同花顺
- 指数 / 个股实时：腾讯（主）、新浪（备）、东财（末）
- K 线 / 分时 / 搜索：东方财富；分时与近 5 日历史分时可回退腾讯点位

## 升级说明

- 首次启动会在现有 `data/tianti.db` 上自动建 `intraday_bars`，不改动已有涨停、K线、自选与设置数据。
- 双击分时能回看多久取决于东财分钟接口；东财不可达时只有腾讯的近 5 个交易日。
