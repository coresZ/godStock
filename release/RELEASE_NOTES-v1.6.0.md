# 天梯 v1.6.0

Windows x64 便携版。解压后双击 `TianTi.exe`，首次启动会在同目录创建 `data/`。原有 `data/` 可直接沿用，无需迁移。

本版新增「**其他 · 同花顺自选**」：登录同花顺 / 问财后，只读同步自己账号下的自选板块与自选股，并在 K 线右侧栏直接查看。

## 新增 · 其他 / 同花顺自选

- 「其他」页新增第二个模块「同花顺自选」：点「登录同花顺」打开应用内登录窗口，在官方页面扫码或账号登录，登录成功后自动同步。
- 同步两路数据：
  - **问财自选板块**：板块名、动态板块条件（如有）、成分股；
  - **同花顺自选股**：扁平自选股列表。
- 只读同步：不保存账号密码、不把 Cookie 写入数据库、不回写问财，也不修改网站上的自选；登录态只留在本机 WebView2 profile，点「退出」会清除本机登录态并清空本地镜像。
- 板块与自选股保留 A 股与场内基金 / ETF（`510300`、`159915` 等），过滤同花顺/中证指数、债券与 B 股；成分股名称用行情批量补齐。
- 板块列表支持按涨幅排序；成分股显示批量行情涨幅；当前 K 线股票高亮。
- 「导入自选」只把成分股 / 自选股复制到本地自选分组，可随时删除。

## 新增 · K 线右侧栏「同花顺」页签

- K 线右侧竖栏从「自选 / 档案」扩展为「自选 / 档案 / 同花顺」三页；「自选」页底部也有一条「同花顺自选」入口直达。
- 点板块就地展开成分股，点股票直接切换 K 线；点股票换图后侧栏保留滚动位置，不再跳回顶部。
- 板块行右侧下载图标整板导入本地自选；成分股行右键可分配到本地自选分组。
- 成分股涨幅来自批量行情接口（80 只/批、前端缓存 60 秒），排序按钮循环「默认 → 涨幅↓ → 涨幅↑」，无行情的股票排在最后。

## 新增 · ETF / 场内基金

- 板块成分股与自选股不再过滤 ETF / 场内基金；「ETF」板块恢复显示成员与名称。
- ETF 行情、日 / 周 / 月 K 线可用：东方财富优先，不可用时回退腾讯**不复权**日线；1 分钟 K 线视图仍只认东财（取不到会明确提示），分时视图可回退腾讯分钟点位。

## 修复

- 点 K 线侧栏「同花顺」里的股票后，列表不再自动滚回顶部。
- 「导入本地自选」从成分股列表底部移到板块行，和股票行分开。
- 同花顺自选板块/自选股表格加入涨幅列与当前选中行高亮。

## 数据来源

- 涨停 / 炸板 / 跌停 / 连板 / 板块 / 历史涨停池：同花顺公开接口。
- 指数与实时报价：腾讯 → 新浪 → 东财；K 线与分时：东财为主、腾讯备用。
- 龙虎榜与游资席位：龙虎榜公开接口（applhb.longhuvip.com）。
- 同花顺自选：问财自选板块接口 + 同花顺自选股接口（登录态由应用内 WebView2 官方登录页建立）。

## 已知限制

- 同花顺 / 问财接口属于页面同源接口，可能随官方页面调整而变化；登录态过期后需要重新登录。
- 自选板块里的「动态板块」只展示条件文本，不执行问财动态选股。
- ETF 在腾讯兜底时为不复权日线（页脚仍写「前复权」，已在文档标注）；ETF 1 分钟 K 线视图在东方财富不可用时没有备用源。
- 富途/同花顺等第三方数据的商用与再分发条款需自行确认；本版只调用官方页面同源接口，未引入付费数据源。
- 游资名号库是静态数据，新席位需要随版本更新。
