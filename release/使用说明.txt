天梯 · A股涨停复盘  v1.0

【启动】
双击 TianTi.exe 即可。
首次启动会在 exe 同级的 data 文件夹中创建 tianti.db。
行情、K线、主题设置和搜索历史都保存在这个 SQLite 数据库里，不使用 JSON 文件。
拷贝时请把 TianTi.exe 和 data 文件夹一起带走；只拷贝 exe 会丢失已缓存的行情。
需要联网才能拉取新的交易日数据；已缓存过的日期和K线可离线查看。
运行依赖 Windows 的 Microsoft Edge WebView2 Runtime（Windows 10/11 通常已安装）。

【页面】
天梯：按当前连续涨停高度分层；最高标为单独的大卡片。
涨停池：高度 / 现价 / 封单 / 首封 / 换手 / 题材 / 主线，可筛选、排序。
K线：日 / 周 / 月 K，EMA 5/10/20/60 与 KDJ(9,3,3)，成交量，前复权。

【快捷键】
Ctrl K   搜索
← →      切换交易日
Esc      关闭浮层
K线内 ← →  移动十字光标
K线内 + -  缩放
滚轮 / 拖动 / 双击  K线缩放、平移、重置

【数据来源】
涨停、连板、板块：同花顺公开接口
K线、指数、搜索：东方财富公开接口
仅供学习复盘，不构成投资建议。

【提示】
exe 未做商业代码签名。若 Windows SmartScreen 提示，选择“更多信息 → 仍要运行”。
数据目录需要在 exe 同级可写；不要放到需要管理员权限的 Program Files 下。
