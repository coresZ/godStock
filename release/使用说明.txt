天梯 · A股涨停复盘  v1.3.0

【启动】
双击 TianTi.exe 即可。
首次启动会在 exe 同级的 data 文件夹中创建 tianti.db。
启动时会先显示原生品牌启动板，主界面就绪后移除；任务栏与开始菜单使用同一枚应用图标。
行情、K线、主题、字号、自选分组和搜索历史都保存在这个 SQLite 数据库里，不使用 JSON 文件。
拷贝时请把 TianTi.exe 和 data 文件夹一起带走；只拷贝 exe 会丢失已缓存的行情。
需要联网才能拉取新的交易日数据；已缓存过的日期和K线可离线查看。
运行依赖 Windows 的 Microsoft Edge WebView2 Runtime（Windows 10/11 通常已安装）。

【页面】
天梯：按当前连续涨停高度分层，同一高度按首次封板时间从早到晚排列；首板悬停可看首封时间、封单、换手与开板次数。
盘口池：涨停 / 炸板 / 跌停三个池子；涨停池可筛选连板、首板、一字、换手和板块；炸板 / 跌停时间由分时采样推断，界面以 ~ 标注。
时间轴：09:15 集合竞价到 15:00，涨停 / 炸板 / 跌停三条泳道；点按落点可跳到逐分钟事件；右上角可导出 TXT 到 data/exports。逐分钟事件可切换正序 / 倒序；炸板票的首封、收盘涨停票的盘中开板以空心点补在对应泳道，日志里是灰色副行，不重复计数。
K线与分时：新增「分时」模式，显示 1 分钟价格线、日内均价线、成交量与悬浮读数；分时双纵轴——左侧价格（指数为点数），右侧为相对昨收的百分比。纵轴刻度可在「自动 / 疏 / 密」之间切换，也可以在左右坐标轴上滚动滚轮微调、双击图表复位；最新价带红点脉冲（盘中）与左右价格标签。指数分时不再绘制无意义的均价线。日 / 周 / 月 / 1分为常用周期，15分 / 30分 / 60分 / 年K收在「更多」。MA、EMA、KDJ 可开关；MA / EMA 支持手动添加 / 删除线条（至少保留一条），每条线可独立选择颜色、粗细、实线或虚线，也可用眼睛按钮单独隐藏；参数会自动保存。
策略：第五个一级入口，分「一进二 / 竞价观察 / 策略库」。一进二先过硬过滤（首板、股价 ≤30 元、流通 ≤200 亿、近 120 日涨停 ≥3 次、近 250 日最高连板 <4 且 20 日涨幅 <60%、板块 ≥3 家涨停），再过质量检查（非一字、首封不晚于 10:00、换手 ≥5%、开板 0 次、封单比 ≥10%），按规则分排序给出候选，其余涨停列进「被剔除」并写明原因。13 项参数可调并保存，候选可导出 TXT、加入自选、点行进 K 线；历史需先在页面里点「回填历史」（近 250 个交易日，后台逐日进行）；竞价只在 09:25–09:30 实时采样，没有历史。以上仅为按固定规则筛出的复盘候选，不构成投资建议。
指数：顶部上证 / 深证 / 创业板显示日内分时，点击进入指数K线。
自选：K线右侧常驻，分「自选 / 档案」两页；支持新建、重命名、删除分组（二次确认）；当前股票加入、涨停池批量加入、右键分配到分组；同组自动去重，一只股票可加入多个分组。
设置：深色 / 浅色主题；界面字号可选 102% / 110% / 118%，使用系统级缩放，K线同步重绘。
控件：所有下拉框为统一的自绘浮层；滚动条为中性灰；数字输入框不显示浏览器上下箭头。

涨停池底部列表可正常纵向滚动；盘口表格的列宽按容器比例分配。

【快捷键】
Ctrl K   搜索
← →      切换交易日
Esc      关闭浮层 / 下拉 / 右键菜单
K线内 ← →  移动十字光标
K线内 + -  缩放
滚轮 / 拖动 / 双击  K线缩放、平移、重置

【数据来源】
涨停、炸板、跌停、连板、板块：同花顺公开接口
指数 / 个股实时报价：腾讯行情为主，新浪备用，东方财富兜底
K线、分时：东方财富为主，腾讯日线/分时备用
搜索：东方财富公开接口
策略历史：近 250 个交易日涨停池按日回填（同花顺）；当日成交额用腾讯批量报价补齐；竞价快照只在 09:25–09:30 实时采集，没有历史
炸板 / 跌停接口不含精确时间字段，时间轴为分时采样推断。
仅供学习复盘，不构成投资建议。

【提示】
exe 未做商业代码签名。若 Windows SmartScreen 提示，选择“更多信息 → 仍要运行”。
数据目录需要在 exe 同级可写；不要放到需要管理员权限的 Program Files 下。
1 分钟 K 线只认东方财富接口：不可用时展示本地缓存并提示，不会用腾讯分时点位凑出假 OHLC；分时折线不受影响，仍会回退腾讯分钟点位。
实时推送：新浪行情 WebSocket 已实测可用，方案见 docs/REALTIME_WS_PLAN.md；当前版本默认仍走 HTTP 轮询，可在仓库中运行 scripts/probe-sina-ws.ps1 自行试连。
