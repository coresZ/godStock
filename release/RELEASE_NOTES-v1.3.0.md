# 天梯 v1.3.0

Windows x64 便携版。解压后双击 `TianTi.exe`，首次启动会在同目录创建 `data/`。

## 2026-11-20 修订

### 策略面板（第 5 个入口）

- 一级导航从四个增加到五个：天梯 / 盘口池 / 时间轴 / K线 / **策略**；`#/strategy` 与其余页面共用同一天作为上下文。
- 策略页分「一进二 / 竞价观察 / 策略库」三个页签，页签行右侧只留历史覆盖与刷新，「运行筛选 / 参数 / 导出」收在上方顶栏，一屏之内能走完一轮复盘。
- 漏斗：首板 → 硬过滤 → 候选 → 观察，四个数字用一条细线串起，只有终点「观察」着铜金；「显示被剔除」就地列出失败规则，不把结果藏在黑箱里。
- 候选表按规则分降序，列为首次封板、封单比、开板、换手、流通、近 120 日涨停、近 250 日最高与规则分；名次用铜金小徽标，其余靠发丝线分行。
- 规则明细抽屉：一条规则一行，给出实际值、阈值与「通过 / 未通过 / 数据不足」三态；数据不足用中性灰，**不计为通过**；抽屉底部可直接查看 K 线或加入自选。
- 参数弹层 13 项数字输入，保存进 SQLite 后立即重算；参数只改阈值，不改写历史。
- 候选可导出 `data/exports/一进二候选_YYYY-MM-DD.txt`，末尾附免责声明；每个策略底部固定一行免责声明。
- 深色「墨夜」与浅色「宣纸」成对适配，1080×720 与三档字号下不横向溢出。

### 一进二规则

- 硬过滤：首板（前一交易日不在涨停池）、股价 ≤ 30 元、流通市值 ≤ 200 亿、近 120 个交易日涨停 ≥ 3 次、近 250 个交易日最高连板 < 4 且 20 日最大涨幅 < 60%、所属板块 ≥ 3 家涨停且至少 1 家连板。
- 封板质量：非一字板、首封不晚于 10:00、换手率 ≥ 5%、开板 0 次、封单比 ≥ 10%。
- 规则分 0–100：首封时间 40%、封单比 30%、板块涨停家数 20%、换手 10%；只有过硬过滤与质量检查的票才进「观察」。
- 其余涨停进入「被剔除」，逐条写明卡在哪条规则；历史数据不足时标记「待补」，不当作通过。
- 筛选只读当日快照与历史缓存，走独立 command，不调用 `save_day`，不会重写当日涨停池、板块或辅助池。

### 数据（全部落 SQLite，不新增 JSON）

- 新增四张表：`limit_up_history`（逐日涨停记录）、`stock_stats`（近 120 日涨停次数、近 250 日最高连板、20 日与 250 日最大涨幅）、`auction_snapshot`（09:25–09:30 竞价快照）、`strategy_profile`（单行参数）。
- 新增 7 个命令：`get_history_status`、`sync_limit_history`、`get_strategy_profile`、`save_strategy_profile`、`run_first_to_second`、`capture_auction`、`get_auction`。
- 「回填历史」在后台按交易日逐日补齐近 250 个交易日涨停池，界面显示进度；单个交易日失败会计入失败数并留下缺口，整批继续，不会中断。
- 涨停池接口不返回成交额：当日抓完后用腾讯批量报价（单次 ≤ 80 只）补齐；补不到保留 0，封单比在界面标为「待补」。
- 竞价只在 09:25–09:30 自动采样并落表，**没有历史、不能补采**；未采集时显示「尚未采集」，不拿 09:30 之后的数据冒充。

### 时间轴

- 「逐分钟事件」新增次级事件：炸板票的首封、收盘涨停票的盘中开板，以空心点补在对应泳道，日志里作为**灰色副行**呈现，不重复计数。
- 以「09:25 封板、09:45 炸板」为例：09:25 是灰色「首封」副行，09:45 是主行「炸板」；主事件数只算 09:45 这一次，副行点击会跳到对应主事件的分钟。
- 逐分钟事件支持正序 / 倒序切换，选择保存在本地，下次进入沿用。

### K 线与分时

- 修复「更多」周期菜单看得见、点不到：工具栏的横向滚动与遮罩会裁掉浮层，现在菜单打开时解除裁剪并提升层级，支持点击外部或 `Esc` 关闭。
- 修复 1 分钟 K 线被画成一条零成交平线：不再把腾讯分时点位当成 1 分钟 OHLC 兜底，1 分钟请求绕过旧缓存，历史里合成的「开盘=最高=最低=收盘、成交量为 0」缓存会被丢弃；确实取不到数据时给出说明，不再伪造一根平线。
- 分时不受影响：1 分钟 K 线不再接受腾讯兜底，但分时折线只读收盘价，东财分钟接口不可用时仍回退腾讯分钟点位；这份回退数据不会写入 1 分钟 K 线缓存，避免把假 OHLC 又存回去。
- 1 分钟与分时的底部时间轴继续固定为开盘、上午收盘/下午开盘、收盘等关键时点，午休合并。

- `README.md` 与 `docs/DESIGN.md` 补上策略入口、策略面板视觉规则、四张新表与「策略只读」边界；新增 `docs/STRATEGY_CONTRACT.md`（策略契约）与 `docs/STRATEGY_YIJINER_PLAN.md`（一进二方案）。

## 说明

- 策略库里的 **P5 回测**仍是「规划中」：当前只输出当日候选与规则证据，没有历史胜率、没有资金曲线。
- 竞价快照只做实时采样，**尚未在真实 09:25 盘口验证过一次完整采集**；没有历史可比，也没有回放。
- 1 分钟线与分时的修复已通过 `pnpm build` 与 `cargo check`；但本机到东方财富分钟接口不可达，**没有在真实分钟行情下截图验证**。分时的腾讯兜底同样只在接口层面验证过，没有盘中画面。
- 1 分钟 K 线在东财分钟接口不可达时只展示本地已有缓存并提示，不再伪造数据；分时仍会走腾讯兜底。
- 历史回填依赖交易日历 `trade_days`：日历为空时会立刻返回而不会静默乱补；单个交易日抓取失败会计入失败数并留下缺口，整批继续，不会中断。
- 炸板 / 跌停时间仍是 `time_preview` 的推断值，界面继续用 `~` 标注，不当成交易所时间。
- 策略筛选是按固定规则筛出的复盘候选，**不构成投资建议**；不交易、不预测、不承诺收益。

## 数据来源

- 涨停 / 炸板 / 跌停 / 连板 / 板块 / 历史涨停池：同花顺
- 指数 / 个股实时：腾讯（主）、新浪（备）、东财（末）
- K线 / 分时 / 搜索：东方财富
- 策略当日成交额：腾讯批量报价

## 升级说明

- 首次启动会自动在现有 `data/tianti.db` 上建 4 张新表，不改动已有涨停、K线、自选与设置数据。
- 历史回填需要手动点「回填历史」，约 250 个交易日，后台逐日进行，期间可以正常使用其它页面。
- 便携版不会上传任何数据；行情与策略结果只写入本地 SQLite。
