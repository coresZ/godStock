# 天梯 v1.2.2

Windows x64 便携版。解压后双击 `TianTi.exe`，首次启动会在同目录创建 `data/`。

## 本次更新

### 实时行情通道

- 指数/个股实时报价改为：**腾讯行情 → 新浪行情 → 东财 push2 → 本地缓存**。
- 指数分时 sparkline 改为腾讯分钟接口，失败时回退东财 1 分钟行情。
- 日/周/月K与1分钟分时在东方财富不可用时自动切换腾讯备用源。
- 涨停池继续使用同花顺，不改变盘口字段和连板数据。
- 顶部指数、K线标题报价、右侧自选行现在都会刷新实时报价。
- 报价失败不会阻塞 K线或整页，继续显示上一份可用数据。
- 缓存报价会标记为「缓存」，实时报价标记为「实时」。

### 稳定性

- 腾讯行情批量报价，一次请求可取多个指数/自选股。
- 20 秒节流刷新，避免并发请求互相覆盖。
- 新增 GBK/UTF-8 响应处理，兼容腾讯、新浪行情编码。
- 实时报价失败时保留上一次成功值，不直接清空界面。

## 数据来源

- 涨停/炸板/跌停/连板/板块：同花顺
- 指数/个股实时：腾讯（主）、新浪（备）、东财（末）
- K线/分时/搜索：东方财富

## 说明

- 盘后最后一个报价仍会显示为最近一次行情时间，这是交易所收盘后的正常状态。
- 便携版不会上传任何数据；行情只写入本地 SQLite。
