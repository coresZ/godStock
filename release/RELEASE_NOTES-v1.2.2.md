# 天梯 v1.2.2

Windows x64 便携版。解压后双击 `TianTi.exe`，首次启动会在同目录创建 `data/`。

## 2026-11-17 修订

### 启动

- 新增原生 GDI 启动板：WebView2 还在初始化时先显示「天梯 / A股涨停复盘」品牌动画，主界面挂载完成后移除，冷启动不再是一片黑屏。
- 主窗口提前设置主题背景色与窗口图标；便携版首次运行会刷新一次 Explorer 图标缓存。
- 设置 AppUserModelID，开始菜单搜索、任务栏不再显示空白图标；任务栏与开始菜单使用同一枚墨夜阶梯图标。

### 天梯分时

- 天梯卡片与最高标的分时走势改为按真实交易时钟绘制：盘中只画到当前时刻，未到 15:00 不会再提前“走完”全天；坐标轴仍固定 09:30 / 11:30 / 15:00。
- 今天的数据只取截至抓取时刻的三分钟采样；旧缓存里多出来的点会被截断，不再把上一交易日的分时尾巴画进来。
- 唯一最高标的分时改用腾讯 1 分钟行情重建，避免接口给到上一交易日的 `time_preview`。
- 盘中每分钟静默刷新涨停池；最新点红点脉冲，收盘后变为静态点。
- 修正封板标记位置与卡片 sparkline 只取最后 64 个点的问题。

### 分时双轴

- 分时图改为双纵轴：左侧价格（指数为点数），右侧相对昨收的百分比；刻度对齐、零点高亮。
- 修复指数分时被“均价线”拉成横线的问题：指数不再用成交额/成交量计算无意义的均价；个股均价增加异常值保护。
- 采用接近 TradingView 的自动纵轴：优先铺满真实波动区间，昨收只在接近数据时保留；涨停股不会再浪费半张图。
- 新增纵轴刻度「自动 / 疏 / 密」三档，左右坐标轴滚轮微调、双击图表复位；刻度倍率与时间轴偏好一起保存。
- 最新价在左右轴显示价格/百分比标签，标签附近不再叠加重复刻度文字。

### 稳定与数据

- 天梯数据盘中 60 秒、分时数据 30 秒自动刷新；收盘后自动停止。
- 盘前抓到的数据可能仍是上一交易日，会给出提示并在开盘后自动刷新。
- 盘中静默刷新不再重播天梯入场动画，「同步中」也不再每分钟闪一次。
- 分时 1 分钟数据首次加载失败后，自动刷新会重新挂载图表，不再停在错误卡上。
- 交易日、盘中时段与分时采样统一按 UTC+8 计算；非中国时区机器不再误判盘前 / 收盘。
- 启动板关闭增加竞态保护：即使原生图层创建极慢，也不会一直盖住主界面。

### 实时推送

- 实测新浪 `wss://hq.sinajs.cn/wskt` 可提供约 3 秒级报价快照；完整接入方案、候选接口、重连/降级设计见 `docs/REALTIME_WS_PLAN.md`。
- 附 `scripts/probe-sina-ws.ps1` 只读探针；当前版本不默认建立 WebSocket 长连接。

## 本次更新

### 实时行情通道

- 指数/个股实时报价改为：**腾讯行情 → 新浪行情 → 东财 push2 → 本地缓存**。
- 指数分时 sparkline 改为腾讯分钟接口，失败时回退东财 1 分钟行情。
- 日/周/月K与1分钟分时在东方财富不可用时自动切换腾讯备用源。
- 涨停池继续使用同花顺，不改变盘口字段和连板数据。
- 顶部指数、K线标题报价、右侧自选行现在都会刷新实时报价。
- 报价失败不会阻塞 K线或整页，继续显示上一份可用数据。
- 缓存报价会标记为「缓存」，实时报价标记为「实时」。

### 时间轴

- 1分钟 K线与分时图的底部时间轴固定为关键交易时点：09:30 / 10:30 / 11:30/13:00 / 14:00 / 15:00。
- 午休合并为一个刻点，未到收盘时只显示已经发生的时点，不再把 14:00 / 15:00 放到错误位置。
- 1分钟数据只保留最近一个交易日，避免跨日数据导致「14:00 后面出现 10:00」。
- 移除了会盖在时间轴上的悬浮日期气泡，日期时间保留在十字光标提示里。

### 稳定性

- 腾讯行情批量报价，一次请求可取多个指数/自选股。
- 20 秒节流刷新，避免并发请求互相覆盖。
- 新增 GBK/UTF-8 响应处理，兼容腾讯、新浪行情编码。
- 实时报价失败时保留上一次成功值，不直接清空界面。

## 数据来源

- 涨停/炸板/跌停/连板/板块：同花顺
- 指数/个股实时：腾讯（主）、新浪（备）、东财（末）
- K线/分时/搜索：东方财富

## 说明

- 盘后最后一个报价仍会显示为最近一次行情时间，这是交易所收盘后的正常状态。
- 便携版不会上传任何数据；行情只写入本地 SQLite。
