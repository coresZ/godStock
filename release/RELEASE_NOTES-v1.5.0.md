# 天梯 v1.5.0

Windows x64 便携版。解压后双击 `TianTi.exe`，首次启动会在同目录创建 `data/`。原有 `data/` 可直接沿用，无需迁移。

本版两个主题：新增第六个入口「**其他 · 游资动态**」；策略面板补上「**批量自选**」并引入**两级缓存**与**休市缓存**。

## 新增 · 其他 / 游资动态

- 左侧导航新增第六个入口「其他」，第一个模块是「游资动态」：顶部是数据日期、上榜个股 / 龙虎榜净买入 / 游资净买入 / 机构净买入与刷新；主体是「总榜 / 游资 / 机构 / 席位」四个页签。
- **总榜**：按净额 / 涨幅 / 席位排序的上榜个股；点开一只票，右侧给出买入 / 卖出营业部（带游资名号、一线 / 顶级 / 知名等级、昨买昨卖、关联标记）、上榜理由与近期上榜日期，并可一键进 K 线。
- **游资**：按内置游资名号库（143 个名号 / 626 条席位）聚合当日席位；点席位读取近期上榜记录（日期、个股、涨幅、买卖与净额）。
- **机构 / 席位**：机构看机构专用席位净买入榜；席位看营业部净额排行与单席位近期记录。
- 连板与板块由东财涨停池补充；当天龙虎榜未发布时自动回退最近交易日，并在日期旁明确标注「回退」，不假装属于今天。
- 席位记录最多显示最近 200 条，标题如实写出实际覆盖区间；同一只票同日同时有当日榜与三日榜时只取当日榜、三日榜单独标「3日」，避免金额翻倍。
- 数据只做进程内缓存（5–30 分钟），不写数据库；点「刷新」可重新拉取。

## 新增 · 策略批量自选

- 观察 / 候选 / 首板 / 硬过滤四类列表的标题行都新增「**批量自选**」按钮（带当前数量，空列表禁用），一次把该阶段当前可见列表加入自选分组。
- 复用现有的分组选择弹层：同组自动去重，完成后回报「已加入 N 只、跳过 M 只重复」；一只股票可加入多个分组。

## 新增 · 策略缓存

- **整份筛选结果缓存**：同一「日期 + 参数 + 历史覆盖 + 当日快照」只算一次，切日期 A→B→A、切页签直接命中；页签行显示「缓存 / 已计算 · 多久前」，悬停可看生成时间。参数保存、历史回填完成、当日快照重载会自动换新；页签行小刷新按钮强制重算。
- **逐日 K 线聚合缓存**（`stock_stats_day`）：只缓存与参数无关的近 20 日最大涨幅、近 250 日涨幅与前一日成交额；过去日期第二次筛选不再重算、也不重复联网补 K 线。
- 只缓存覆盖完整的历史日期：**当天不写入**（避免盘中半成品在次日回看时被当成历史定稿）；首次未命中时每只硬候选最多补拉一次当日 K 线。
- 修复历史日期筛选的一处偏差：K 线指标此前会用到 `as_of` 之后的数据（look-ahead），现已按交易日截断。

## 改进 · 休市缓存

- 交易时段保持原有节流：天梯池 60 秒、分时 30 秒；收盘即停。
- 收盘后 **15:05 补拉一次当日定稿快照**，之后与周末 / 节假日只读本地缓存，不再后台联网（失败会按 60 秒节流重试到成功或跨日）。
- 休市启动时，若指数条或 K 线缓存还停在上一次收盘，会各补一次当天收盘；打开图表时若缓存落后于最近收盘日也会自动补一次，已新鲜的图表不会重复请求。
- 过去日期不再自动补拉；手动「刷新 / 重试」不受此限制。

## 视觉与可读性

- 「游资动态」沿用墨夜 / 宣纸两套主题与整套纸面语言：发丝线分隔、铜金只落在席位名号与连板标记上，不引入霓虹色块。
- 新增小字铜金 token `--brass-text`（墨夜 `#e3c58c` / 宣纸 `#6a4e1f`），修正浅色主题下小字对比度不足；页头指标标签与「最高」数字的对比度同步提高。
- 1080×720 最小窗口下，游资动态与策略页的表格均无横向溢出；策略页「批量自选」与缓存状态与既有按钮同节奏。

## 数据来源

- 涨停 / 炸板 / 跌停 / 连板 / 板块 / 历史涨停池：同花顺公开接口。
- 指数与实时报价：腾讯 → 新浪 → 东财；K 线与分时：东财为主、腾讯备用。
- 龙虎榜与游资席位：龙虎榜公开接口（applhb.longhuvip.com），连板 / 板块由东方财富涨停池补充。

## 已知限制

- 席位记录受上游单页上限约束，最多显示最近 200 条，不是严格「30 天」；界面以实际覆盖区间为准。
- 收盘补拉失败会每 60 秒重试一次，直到成功或跨日；启动时仍会刷新交易日历并取一次自选报价。
- 1 分钟 / 分时 K 线的收盘补拉只按日期判断，当天较早的 1 分钟缓存不会自动补到 15:00（跨日会补）。
- 过去日期若保存的是盘中半成品快照，不会自动修复，需要手动「重新拉取」。
- 游资名号库是静态数据，新席位需要随版本更新；接口异常时页面会显示上游提示文案，可重试。
- 本轮未在真实盘中波动下做长时间浸泡测试；发布构建由 GitHub Actions 在 tag 上完成。
