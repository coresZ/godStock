# 天梯 · 设计说明

## 产品定位

把「涨停复盘」从一张信息堆叠的表格，重做成一台 **看得见高度** 的复盘仪器。

核心用户动作只有三个：

1. 今天市场最高到几板？谁在带队？
2. 主线在哪里，连板结构是否健康？
3. 点开一只票，K线、EMA、KDJ 是否支持这个高度？

因此信息架构被收束为五个入口：**天梯 / 涨停池 / 时间轴 / K线 / 策略**。日期是全局上下文，指数与市场统计只在需要时出现。策略是**规则复盘台**：把一条战法写成可读的规则，输出候选、剔除理由与免责声明——不是交易台，也不是荐股器。

1.1 迭代把「涨停池」扩展为**盘口池**（涨停 / 炸板 / 跌停），并新增一条从集合竞价到收盘的**盘口时间轴**：高度回答「谁最强」，时间轴回答「什么时候发生」。

1.2 迭代把 K线从「一张图」整理成一台**报价仪器**：标题区只保留名称、代码、价格、涨跌与四个 OHLC 读数；自选与档案移到右侧常驻竖栏，看盘空间更大；常用周期收敛为 1分 / 日 / 周 / 月，15/30/60分与年K进入「更多」；MA/EMA 每一条线都能改颜色、粗细、虚实。整体字号放大，并提供三档系统级缩放比例。

1.2.1 在此基础上补三件事：**分时模式**（1分钟价格线、日内均价、成交量）、**可增删和单线隐藏的均线编辑器**、**统一的自绘下拉框**。分时的涨跌幅与四个读数按「昨收 → 当日累计」计算，不再使用分钟线自身的单根涨跌幅；下拉菜单改为挂在顶层的浮层，避免被弹层裁切，滚动条统一为中性灰。

1.2.2 收束「启动、时钟、纵轴」三处：**启动板**改为主窗口内的原生 GDI 子层，先于 WebView2 绘制品牌动画，主界面挂载后移除，冷启动不再黑屏；**天梯分时**按真实交易时钟截断，09:30 / 11:30 / 15:00 刻度固定，盘中只画到当前分钟，最新点盘中脉冲、收盘转静态；**分时纵轴**升级为双轴——左侧价格（指数为点数）、右侧相对昨收的百分比，刻度支持自动 / 疏 / 密，也可在左右轴上滚轮微调、双击复位。盘中天梯池 60 秒、分时 1 分钟数据 30 秒静默刷新，收盘即停；实时推送仍是 HTTP 轮询，WebSocket 方案另见 `docs/REALTIME_WS_PLAN.md`。

1.3.0 新增第五个入口「**策略**」：一进二复盘台。它把一条战法拆成硬过滤与质量检查，逐条给出证据、阈值与剔除原因，参数全部可调；数据侧补齐近 250 个交易日涨停历史、当日成交额与 09:25 竞价快照。产品边界随之明确为「提供固定规则筛选与观察清单，不构成投资建议」。

1.3.1 收尾两处：逐分钟事件的行内时点移入悬停提示，首封 / 开板补充点改为虚线空心并置灰；1 分钟线与分时改为显式数据来源标记，分时走腾讯兜底时脚注标注来源，1 分钟线失败时给出「可切到分时」的提示。

## 视觉方向

### 概念：「墨夜天梯」

不是常见的蓝黑 SaaS 仪表盘，而是一张 **夜色中的金融手稿**：

- 深墨底 `#0B0C0F`，暖象牙文字 `#E9E3D7`；
- 铜金 `#C6A15B` 只用于「高度、封单、关键动作」；
- 朱砂 `#E15A4D` / 青瓷 `#57A68E` 只表示涨跌；
- 大面积留白、细发丝线、几乎无阴影；让数字和阶梯自己说话。

浅色主题「宣纸」使用 `#F2EDE3` 暖纸底与更深一档的铜金/朱砂/青瓷，保留同一结构。

### 字体

- 展示：Noto Serif SC；沉稳、有笔锋，适合「天梯」与高度数字。
- 数据：Fraunces（日期、层高数字）+ IBM Plex Mono（代码、价格、封单、时间）。
- 正文：Noto Sans SC。

字体全部本地打包，不依赖网络；只保留中文/拉丁所需子集，兼顾清晰与体积。

### 版式

- 顶部是「日期 + 市场读数」，日期是第一视觉层级；右侧指数退到辅助位置。
- 天梯使用左侧粗刻度 + 横向卡片带。层级越高，卡片越宽、信息越丰富；**唯一最高标升级为整行 feature 卡片**，这是整个产品唯一一次「大声说话」。
- 首板数量多，改用 5 列高密度小卡，降低视觉重量；「5天4板」这类历史高度会替代板块名展示，避免把首板误读成弱票。
- 右侧「主线 / 封单 / 封板时点」是一条连续的阅读带，而不是三张同质卡片。
- 涨停池是一张可排序的「盘口纸」；不使用斑马纹，用发丝线和行距建立节奏。炸板池以铜金标记「炸板」，跌停池以青瓷标记「跌停」，与涨停的朱砂形成三色语义。
- 盘口时间轴把 09:15–15:00 压成一条水平线，午休折叠；涨停 / 炸板 / 跌停各占一条泳道。落点不是精确到秒的交易所流水，而是可读的「时间点 + 股票簇」，下方逐分钟事件负责细节。炸板票的首封、收盘涨停票的盘中开板用**虚线空心点**补在对应泳道并置灰，只作轨迹，不重复计数；逐分钟事件中以灰色副行呈现，不计入主事件数。副行与主行都只写「炸板 / 首封 / 开板」与开板次数，**具体时点不写进行内**，留给 hover 提示与导出 TXT。
- 自选分组是 K线右侧的一列「竖抽屉」：自选 / 档案两个页签，分组横带在上，股票以 39px 的纸片行纵向排列；比底部横条多出数倍的可视空间，也更接近真实看盘软件的侧栏。颜色只在涨幅与分组状态上出现。
- K线标题区按「身份 → 报价 → 当日读数」从左到右排列；加自选与上一只/下一只下沉到工具条，避免插在最高价与价格之间。所有元素按底边对齐，形成一条安静的水平基线。

### 动效

- 只保留一次编排：进入天梯时，各层自下而上轻微浮现；卡片和层高错峰 46ms。
- 启动板只播一次：至少展示约 1.15 秒，主界面就绪后立即移除，不重复、不阻塞输入。
- 悬停只做边框、颜色和 1px 位移；不弹跳、不缩放。
- 所有动效遵循 `prefers-reduced-motion`。

## 策略面板

第五个一级入口，沿用同一套纸面语言：发丝线分隔、铜金只落在「名次、观察终点、规则分」上，涨跌仍由朱砂 / 青瓷表达；不新增大色块，不做仪表盘式堆叠。

- **页签**：一进二 / 竞价观察 / 策略库，与盘口池的分段同一节奏；页签行右侧只留历史覆盖与刷新，「运行筛选 / 参数 / 导出」放在上方顶栏，一屏之内可完成一轮复盘。
- **漏斗**：首板 → 硬过滤 → 候选 → 观察，四个数字用一条细线串起，只有终点「观察」着铜金；「显示被剔除」展开后逐只列出失败规则，不把结果藏在黑箱里。
- **候选表**：按规则分降序，列只保留首封、封单比、开板、换手、流通、近 120 日涨停、近 250 日最高与规则分；名次用铜金小徽标，其余靠发丝线分行。
- **候选池其余**：没进观察名单的候选收成一条低调纸片带，点按仍能看逐条规则。
- **规则明细抽屉**：从行尾的列表图标打开，一条规则一行，给出实际值、阈值与「通过 / 未通过 / 数据不足」三态；数据不足用中性灰，不计为通过；抽屉底部可直接「查看 K 线 / 加入自选」。
- **参数弹层**：13 项数字输入 + 保存参数，复用 K线指标参数弹层的样式，保存后立即重算；参数只改阈值，不改写历史。
- **策略库**：一列卡片，分别标「已启用 / 盘中 / 规划中 / 接入口」；卡片只写规则与数据依赖，不写收益。
- 每个策略底部固定一行免责声明，字号小、颜色淡，不随滚动消失。

未来策略共用同一套「规则 → 候选 → 证据 → 免责声明」结构：新增只补规则表、参数与文案，不新开导航，也不另起一套表格样式。

## 关键交互

- 点击任意股票卡片 / 表格行 → 个股 K线。
- 点击主线板块 → 自动切到涨停池并筛出该板块。
- 点击天梯右上角的同步时间 → 重新拉取当日数据。
- 盘口池：涨停 / 炸板 / 跌停切换，筛选与板块切换只更新表格与工具条，不触发整页进入动画。
- 盘口时间轴：点按任一落点，滚动到对应的逐分钟事件；股票纸片可直接进入 K线。
- K线：滚轮缩放、拖动平移、十字光标读数、MA/EMA/KDJ 开关与参数弹层；1分 / 日 / 周 / 月常用周期外露，15/30/60分与年K进入「更多」；每条 MA/EMA 可独立设置颜色、粗细、虚实，可增删线条（至少一条），也可单线隐藏；分时模式读取 1 分钟数据，绘制价格线、成交量加权均价线与成交量柱。
- 分时：双纵轴（左侧价格、指数为点数，右侧昨收百分比）；纵轴刻度自动 / 疏 / 密三档，左右轴滚轮微调、双击复位；指数不绘制均价线，最新价带红点脉冲（盘中）与左右价格标签，收盘后转静态。
- 下拉框：项目内统一使用 `.dd` 自绘浮层，菜单挂在 `body` 的顶层 portal 上，位置在视口内自动翻转；不使用系统原生 select 弹层，避免深色主题下出现灰白菜单或被弹层裁切。滚动条与菜单滚动条都使用中性灰，不跟随铜金强调色。
- 天梯：同一高度按首次封板时间排序；首板卡片悬停展示首封、封单、换手、开板次数，避免把信息塞进已经密集的卡片；分时走势按真实交易时钟截断，盘中只画到当前时刻，最新点盘中脉冲、收盘转静态。
- 时间轴：可导出 TXT 到 `data/exports/`；字号与行距按阅读优先级放大，落点、逐分钟事件与导出入口在同一视线内；逐分钟事件可切换正序 / 倒序。
- 自选：K线右侧常驻；新建 / 重命名 / 二次确认删除分组；当前股票加入、涨停池批量加入、右键分配到其他分组；同组去重、跨组可重复。
- 策略：切换页签只更新面板内容；「回填历史」在后台逐个交易日补齐并显示进度；「运行筛选」后点表格行进 K线，点行尾的规则明细图标打开抽屉，行尾「＋」把候选加入自选分组；「显示被剔除」就地列出失败规则。
- 策略参数：13 项数字输入，保存到 SQLite 后立即重算；参数只影响下一次筛选，不重写历史。
- 策略导出：候选清单写 `data/exports/一进二候选_YYYY-MM-DD.txt`，末尾附免责声明。
- 竞价观察：只在 09:25–09:30 有效，采集一次即落表；未采集时显示「尚未采集」，不拿 09:30 之后的数据冒充。
- `Ctrl K` 随时搜索；最近查看存在 SQLite 中。

## 技术落地

- Tauri 2 + Rust + 原生 TypeScript / Vite。
- Rust 侧负责网络抓取、SQLite 读写、交易日历、搜索、窗口控制。
- 前端不直接碰网络，也不持久化 JSON；只消费 Tauri command 的结构化数据。
- SQLite 使用 WAL；K线、涨停、炸板 / 跌停辅助池、板块、指数、设置、自选分组、搜索历史均有独立表。
- 行情不依赖单一接口：实时报价按 腾讯 → 新浪 → 东财 → 本地缓存 逐级回退，K线 / 分时以东财为主、腾讯备用；失败时保留上一份可用值，并在界面区分「实时 / 缓存」。
- 1 分钟 K 线与分时对备用源的要求不同：腾讯分钟接口是逐笔线，只有收盘价，凑不出 OHLC，所以 1 分钟 K 线只认东方财富，取不到就用本地缓存并提示；分时只读收盘价，仍允许回退腾讯，脚注会标注「腾讯分时点位（仅收盘价）」。腾讯兜底数据不写入 1 分钟 K 线缓存，分时抓到的真实 1 分钟数据则照常写缓存。所有周期都先读缓存、再后台刷新，1 分钟不再例外，离线也能打开。
- 盘中刷新是固定节流：天梯池 60 秒、分时 1 分钟数据 30 秒，窗口隐藏时暂停，收盘自动停止；启动板由前端 `app_ready` 关闭，15 秒看门狗兜底，避免永远停在启动画面。
- 炸板 / 跌停池接口没有精确时间字段，时间轴使用 `time_preview` 的 3 分钟采样推断，并在界面以 `~` 明确标注，避免把推断值伪装成交易所时间。
- 策略只读日快照与历史缓存：筛选走独立 command，不调用 `save_day`，不会重写当日快照、板块与辅助池。
- 新增四张表：`limit_up_history`（逐日涨停记录）、`stock_stats`（近 120 日涨停次数、近 250 日最高连板、20 日最大涨幅）、`auction_snapshot`（09:25–09:30 竞价快照）、`strategy_profile`（单行参数）。
- 250 天历史回填走同花顺涨停池按日接口，一页一日；抓取失败的交易日计入失败数并留空，下次同步会再补，只写历史表，不复用当日快照路径。
- 涨停池接口不返回成交额：当日抓完后用腾讯批量报价（单次 ≤80 只）补齐，失败保留 0，封单比在界面标为待补。
- 竞价没有历史，只在 09:25–09:30 实时采样落表；缺口如实显示，不从 1 分钟线反推。
- 以上全部进 SQLite，不新增 JSON。
- 界面字号通过 Tauri WebView 的系统缩放实现，而不是 CSS transform；这样字体、Canvas K线与交互命中区域一起缩放，不会出现模糊或错位。
- 便携版数据目录固定在 exe 同级 `data/`。

## 边界

- 提供固定规则筛选与观察清单，不构成投资建议；不交易、不预测、不承诺收益、不做社区。
- 只陈列高度、封单、时间、规则证据与指标。
- 数据来自公开接口，接口不可用时优先展示本地缓存并明确标注。
